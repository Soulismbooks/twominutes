Live setup checklist

  1. Review this prototype in the browser.
  2. Choose an explicit admin email allow-list in Cloudflare Access.
  3. Create a dedicated D1 database for drafts (none is currently present).
  4. Provision a separate API Worker and keep credentials in secrets.
  5. Implement publishing with reviewable GitHub changes and the existing validator.
  6. Connect the selected analytics provider and update the privacy notice.
  7. Test access denial and publishing in a staging environment before launch.
